# 📚 ระบบคอร์สแวร์ วิทยาการคำนวณ (เทคโนโลยีความจริงเสริม - AR)

ระบบคอร์สแวร์ (บทเรียนคอมพิวเตอร์ช่วยสอน) รายวิชาวิทยาการคำนวณ (ว31103) สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 5 พัฒนาในรูปแบบ Single Page Application (SPA) ทำงานร่วมกับฐานข้อมูลระบบหลังบ้าน (BaaS) จาก **Supabase**

## ✨ ฟีเจอร์หลัก

### 👨‍🎓 สำหรับผู้เรียน (นักเรียน)
*   **ระบบยืนยันตัวตน:** เข้าสู่ระบบด้วยรหัสนักศึกษา 11 หลัก โดยอ้างอิงจากฐานข้อมูลรายชื่อที่ผู้สอนเตรียมไว้ (อีเมลจำลอง)
*   **ระบบทดสอบ:** แบบทดสอบก่อนเรียน (Pre-test) และหลังเรียน (Post-test) สุ่มข้อสอบคู่ขนานชุด A และ B (ตามเลขท้ายรหัสนักศึกษา)
*   **เนื้อหาบทเรียน:** 5 หน่วยการเรียนรู้ พร้อมคำถามแทรกเพื่อทบทวนความเข้าใจก่อนผ่านด่าน
*   **WebAR:** แสดงผลโมเดล 3 มิติ (ไฟล์ `.glb`) ผ่านเบราว์เซอร์ และรองรับการส่อง AR บนสมาร์ทโฟนโดยไม่ต้องโหลดแอปพลิเคชันเพิ่ม (ใช้ `<model-viewer>`)
*   **ระบบส่งงาน:** ส่งผลงานปฏิบัติการ AR (แนบลิงก์ หรืออัปโหลดไฟล์ภาพ/วิดีโอ ไม่เกิน 20MB)
*   **แดชบอร์ดสรุปผล:** ดูคะแนนสอบ การพัฒนาการด้วยค่า Normalized Gain (Hake, 1998) และดูข้อเสนอแนะจากการตรวจงานของผู้สอน

### 👩‍🏫 สำหรับผู้สอน (อาจารย์)
*   **แผงควบคุม (Dashboard):** ดูความคืบหน้า คะแนนสอบ และค่า Gain ของนักเรียนทุกคนแบบเรียลไทม์
*   **ระบบตรวจงาน:** ตรวจสอบลิงก์หรือดาวน์โหลดไฟล์ผลงานของนักเรียน ให้คะแนน และพิมพ์ข้อเสนอแนะ
*   **จัดการสื่อเพิ่มเติม:** อัปโหลดไฟล์สื่อ (PDF, PPTX, DOCX ไม่เกิน 50MB) หรือแนบลิงก์วิดีโอให้นักเรียนศึกษาเพิ่มเติม
*   **ส่งออกข้อมูล:** ส่งออกคะแนนทั้งหมดเป็นไฟล์ CSV (รองรับภาษาไทยสำหรับเปิดใน MS Excel)

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
*   **Frontend:** HTML5, JavaScript (Vanilla), Tailwind CSS (via CDN)
*   **Backend & Database:** Supabase (PostgreSQL, Authentication, Storage, Row Level Security)
*   **AR Component:** Google `<model-viewer>` (v3.4.0)
*   **Fonts:** Google Fonts (Sarabun)

## 📁 โครงสร้างไฟล์
*   `courseware.html`: ไฟล์เว็บแอปพลิเคชันหลัก รวมโครงสร้าง หน้าตา (UI) และลอจิก (JS) ทั้งหมด
*   `setup.sql`: สคริปต์สำหรับสร้างตาราง, ทริกเกอร์, นโยบายความปลอดภัย (RLS) และค่าเริ่มต้นใน Supabase

## 🚀 คู่มือการติดตั้งและใช้งาน (Setup Guide)

### ขั้นตอนที่ 1: เตรียมฐานข้อมูลบน Supabase
1. สมัครสมาชิกและสร้างโปรเจกต์ใหม่ที่ [Supabase](https://supabase.com/)
2. ไปที่เมนู **Authentication > Providers** เลือก Email 
3. **สำคัญ:** ปิดการตั้งค่า `Confirm email` และ `Secure email change` เพื่อให้นักเรียนล็อกอินได้ทันทีโดยไม่ต้องยืนยันอีเมลจริง
4. ไปที่เมนู **SQL Editor** คัดลอกเนื้อหาจากไฟล์ `setup.sql` วางและกด **RUN**
5. นำเข้ารายชื่อนักเรียน: ไปที่เมนู **Table Editor** เลือกตาราง `students` กด **Insert > Import data from CSV** อัปโหลดไฟล์ที่มีคอลัมน์ `id, title, first_name, last_name, section`

### ขั้นตอนที่ 2: ตั้งค่าบัญชีผู้สอน
1. ในหน้าเว็บแอปพลิเคชัน (หรือผ่าน API) ให้กดสมัครสมาชิกใหม่ด้วยอีเมลผู้สอน (เช่น `teacher@khoknongna.ac.th`)
2. กลับไปที่ **SQL Editor** ใน Supabase เลื่อนไปท้ายสุดของไฟล์ `setup.sql`
3. ลบเครื่องหมาย `--` หน้าคำสั่ง `INSERT INTO teachers...` ออก 
4. แก้ไขอีเมลในคำสั่งให้ตรงกับอีเมลที่สมัครไว้ แล้วกด **RUN** (รันเฉพาะบรรทัดนั้น) เพื่อให้สิทธิ์ผู้สอน

### ขั้นตอนที่ 3: เชื่อมต่อ Frontend
1. ใน Supabase ไปที่เมนู **Project Settings > API**
2. คัดลอกค่า **Project URL** และ **anon / public key**
3. เปิดไฟล์ `courseware.html` ด้วย Text Editor
4. ค้นหาตัวแปรต่อไปนี้บริเวณส่วนบนของแท็ก `<script>` และใส่ค่าที่คัดลอกมา:
   ```javascript
   const SUPABASE_URL = 'ใส่_URL_ของคุณที่นี่';
   const SUPABASE_ANON_KEY = 'ใส่_ANON_KEY_ของคุณที่นี่';
   ```
5. บันทึกไฟล์ และนำไฟล์ `courseware.html` ไปอัปโหลดขึ้น Web Hosting (เช่น GitHub Pages, Vercel, Netlify) หรือเปิดในเบราว์เซอร์เพื่อใช้งานได้ทันที

## 🔒 ความปลอดภัย (Security)
ระบบนี้ใช้ **Row Level Security (RLS)** ของ PostgreSQL อย่างเข้มงวด:
*   ผู้ใช้ที่ไม่ระบุตัวตน (Anon) ไม่สามารถเข้าถึงตารางใดๆ ได้
*   นักเรียนสามารถเข้าถึง (Select/Insert/Update) ได้เฉพาะแถวข้อมูลที่เป็นของตนเองเท่านั้น (อ้างอิงจาก `auth.uid()`)
*   นักเรียนไม่สามารถแก้ไขคะแนน (`score`) หรือคำวิจารณ์ (`teacher_comment`) ในตารางงานที่ส่งได้
*   Storage Buckets ถูกจำกัดสิทธิ์ให้แต่ละคนจัดการได้เฉพาะโฟลเดอร์ของตนเอง และจำกัดขนาด/ชนิดไฟล์ผ่านนโยบาย SQL

## ⚠️ ข้อควรระวังและคำแนะนำ
*   **การทดสอบ WebAR:** ฟีเจอร์ส่อง AR โมเดล 3 มิติบนพื้นที่จริง ต้องเปิดใช้งานบนสมาร์ทโฟนหรือแท็บเล็ต (iOS/Android) ที่รองรับ ARCore หรือ ARKit และจำเป็นต้องทำงานผ่านโฮสต์ที่มี **HTTPS** เท่านั้น
*   **การตั้งรหัสผ่าน:** เนื่องจากระบบใช้อีเมลจำลอง (เช่น `11111111101@khoknongna.ac.th`) นักเรียนควรจำรหัสผ่านที่ตนเองตั้งตอนสมัครให้ดี เพราะฟีเจอร์ "ลืมรหัสผ่าน" จะไม่สามารถส่งอีเมลแจ้งเตือนได้จริง
*   **การแก้เนื้อหาบทเรียน:** เนื้อหาบทเรียนและข้อสอบถูกเขียนฝัง (Hardcode) ไว้ในตัวแปร `COURSE_DATA` ในไฟล์ `courseware.html` หากต้องการแก้ไขคำถามหรือเนื้อหา สามารถแก้ไขได้ในไฟล์ HTML โดยตรง
